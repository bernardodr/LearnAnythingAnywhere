# Mission: System Design Interviews

## Why
Pass the system design round of a Big Tech mid-level (L4/E4-style) software engineering loop. Coming from an early-career background with little hands-on architecture experience, the aim is to walk into a 45–60 minute "Design X" round and deliver a clear, working design.

## Success looks like
- Run any "Design X" prompt end to end with a repeatable framework, within the time limit
- Lead the early phases unprompted: requirements, core entities, API, high-level design ([what mid-level is expected to do](https://hellointerview.com/blog/the-system-design-interview-what-is-expected-at-each-level))
- Explain what each common building block does (load balancer, cache, queue, DB choices) and why it's there, when asked
- Handle interviewer-led deep dives on classic problems (URL shortener, news feed, chat, rate limiter…)
- Complete several timed mock problems with critique and see measurable improvement

## Constraints
- No fixed deadline, so learn at an unhurried pace and space sessions out
- Day-to-day stack: Java / Kotlin / Go
- Prefers a mix of videos, short reading, quizzes and mock problems with critique

## Out of scope
- Staff+ level expectations (multi-team or platform strategy)
- Low-level / object-oriented design rounds
- ML system design
